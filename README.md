# Mr. Variable Picker

ラズベリーパイとカメラを利用して、店舗などの実空間における顧客の行動・属性をリアルタイムに分析するプロトタイプです。

カメラ映像から顔を検出し、人物ごとにIDを付与して追跡します。そのうえで、年齢・性別・表情を推定し、一定時間以上滞在した人物を `stay`、短時間で通過した人物を `pass` としてCSVに記録します。

## 概要

「映像を撮る」だけではなく、映像から取得した情報を**人物単位の時系列データへ変換し、店舗分析に利用できる形へ落とし込む**ことを目的としています。

```text
カメラ映像
   ↓
顔検出（OpenCV Haar Cascade）
   ↓
人物追跡（Centroid Tracker）
   ↓
年齢・性別・表情推定（OpenVINO）
   ↓
人物ごとの時系列データを蓄積
   ↓
滞在時間・代表属性を算出
   ↓
CSVへ出力
```

## 主な機能

- Webカメラからのリアルタイム映像取得
- OpenCV Haar Cascadeによる顔検出
- Centroid-based Trackingによる人物ID追跡
- OpenVINOによる年齢・性別推定
- OpenVINOによる表情推定
- 複数フレームを利用した属性の安定化（年齢：中央値、性別・表情：最頻値）
- 人物ごとの滞在時間計測
- 滞在時間2秒以上を `stay`、それ未満を `pass` として分類
- 分析結果のCSV保存

## 各ファイルの役割

### `main.py`

カメラからフレームを取得し、顔検出 → 人物追跡 → 属性推定 → 分析 → 画面表示までの一連の処理を実行します。

### `tracker.py`

Centroid Trackerを実装しています。検出された顔のバウンディングボックスから重心を計算し、フレーム間の距離を利用して人物IDを維持します。

### `analytics.py`

人物ごとの属性・時系列データを管理します。追跡中のデータから年齢・性別・表情を安定化し、滞在時間を算出してCSVへ出力します。

## 出力データ

実行すると `logs/` ディレクトリにCSVが生成されます。

```csv
end_timestamp,gender,age_stable,top_expression,result,total_dwell_sec
2026-01-27 14:30:12,Male,34,Neutral,stay,4.82
2026-01-27 14:30:18,Female,27,Happy,pass,0.93
```

各レコードは、1人の追跡が終了したタイミングで保存されます。

## 実行

### 1. リポジトリを取得

```bash
git clone https://github.com/hiromu2001/Mr.-Variable-Picker.git
cd Mr.-Variable-Picker
```

### 2. 依存ライブラリをインストール

```bash
pip install opencv-python numpy scipy openvino
```

### 3. カメラを接続して実行

```bash
python main.py
```

終了する場合は映像ウィンドウ上で `q` キーを押してください。

## 分析ロジック

### 人物追跡

顔検出によって得られたバウンディングボックスの中心座標を利用します。前フレームまでに登録された人物の重心と現在フレームで検出された重心とのユークリッド距離を計算し、最も近い人物同士を対応付けます。

人物が一時的に検出できなくなった場合にも、一定フレーム数まではIDを保持します。

### 属性の安定化

カメラ映像では1フレームごとの推定結果が揺れる可能性があります。そのため、画面表示では直近5フレームの結果を利用します。

- 年齢：中央値
- 性別：最頻値
- 表情：最頻値

人物が追跡終了した際には、追跡中に蓄積したデータ全体から最終的な代表値を算出します。

### 滞在判定

人物の最初の検出時刻と最後の検出時刻から滞在時間を算出します。

```text
滞在時間 >= 2秒 → stay
滞在時間 <  2秒 → pass
```

この閾値は `analytics.py` の `DWELL_THRESHOLD` から変更できます。

## このプロジェクトで取り組んだこと

画像認識モデルを単体で動かすだけではなく、**「画像 → 人物 → 時系列データ → 分析結果」**という一連のデータ処理パイプラインとして実装しています。

リアルタイム映像では推論結果がフレームごとに変動するため、人物追跡と複数フレームの集約処理を組み合わせ、分析データとして扱いやすい形に変換しています。
